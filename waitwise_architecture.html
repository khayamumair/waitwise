Agent Layer
monitor.py
Scores all 503 patients by how many risk rules they hit. Returns top 3.
SQL No LLM. Pure DuckDB queries.
reads: patients, contact_log
triage.py
Retrieves NHS rules from ChromaDB. Sends patient + rules to Nemotron. Gets back risk level, score, reason.
RAGLLM Nemotron via vLLM.
reads: vector_store/ · writes: triage_results
communication.py
Generates coordinator memo + patient letter per flagged case.
LLM Nemotron via vLLM.
writes: communications
